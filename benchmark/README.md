# Benchmark Layout

The benchmark corpus is split into two clearly separated tiers:

- `analogcoder_pro/`
  - Main pedagogical benchmark currently used by the framework and paper
  - Contains the 28 imported AnalogCoder-Pro netlists and their manifest

- `industrial/`
  - Planned harder benchmark tier for more industry-representative circuits
  - Contains the industrial-style manifest and placeholders for future netlists/specs

Current canonical pedagogical benchmark path:
- `benchmark/analogcoder_pro`

Current industrial extension path:
- `benchmark/industrial`
